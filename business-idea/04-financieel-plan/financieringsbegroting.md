# Financieringsbegroting

Overzicht van hoe de investeringen gefinancierd worden.

| Financieringsbron | Bedrag (indicatie) | Toelichting |
|---|---|---|
| Eigen geld (spaargeld) | | Eigen inbreng, verkleint financieringsbehoefte en toont commitment naar financiers |
| Microkrediet (bv. Qredits) | tot €50.000 | Veelgebruikt door Nederlandse starters, laagdrempeliger dan bank |
| Familie/vrienden lening | | Vaak flexibelere voorwaarden dan bank |
| Crowdfunding | | Past goed bij een duurzaamheids-/circulair verhaal — kan ook als marketing/validatie dienen |
| Subsidie/regeling circulaire economie | | Check gemeentelijke en provinciale subsidies voor circulaire ondernemers |
| Bancaire lening | | Meestal pas relevant bij grotere schaal/zekerheden |
| **Totaal financieringsbehoefte** | **= totaal investeringsbegroting** | |

*Tip: because this is a circular-economy / waste-reduction business,
specifically check Dutch and EU circular economy grants/subsidies
(gemeente, provincie, RVO) — these are often available for exactly this type
of business model and can reduce the amount of debt/equity financing
needed.*
