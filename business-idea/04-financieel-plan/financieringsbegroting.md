# Financieringsbegroting

Overzicht van hoe de investeringen gefinancierd worden.

| Financieringsbron | Bedrag (indicatie) | Toelichting |
|---|---|---|
| Eigen geld (spaargeld) | | Eigen inbreng, verkleint de financieringsbehoefte en toont commitment richting financiers |
| Microkrediet (bv. Qredits) | tot € 50.000 | Veelgebruikt door Nederlandse starters, laagdrempeliger dan een bank |
| Lening van familie/vrienden | | Vaak flexibelere voorwaarden dan een bank |
| Crowdfunding | | Sluit goed aan bij een duurzaamheids-/circulair verhaal — kan ook als marketing/validatie dienen |
| Subsidie/regeling circulaire economie | | Gemeentelijke en provinciale subsidies voor circulaire ondernemers controleren |
| Bancaire lening | | Doorgaans pas relevant bij grotere schaal/zekerheden |
| **Totale financieringsbehoefte** | **= totaal investeringsbegroting** | |

*Tip: aangezien dit een circulaire-economie-/afvalreductiebedrijf betreft,
specifiek Nederlandse en Europese subsidies voor de circulaire economie
controleren (gemeente, provincie, RVO) — deze zijn vaak beschikbaar voor
precies dit type businessmodel en kunnen de benodigde vreemd-/eigen
vermogen-financiering verlagen.*
